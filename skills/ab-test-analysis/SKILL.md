## A/B 测试分析

以统计严谨性评估 A/B 测试结果，并把发现转化为清晰的产品决策。

### 背景

你正在为 **{user_input}** 分析 A/B 测试结果。

如果用户提供了数据文件（CSV、Excel 或分析工具导出），直接读取并分析。需要时生成 Python 脚本进行统计计算。

### 操作步骤

1. **理解实验**：
   - 假设是什么？
   - 改了什么（变体是什么）？
   - 核心指标是什么？有护栏指标吗？
   - 测试运行了多久？
   - 流量分配比例是多少？

2. **校验测试设置**：
   - **样本量**：样本是否足以检出预期效应量？
     - 使用公式：n = (Z²α/2 × 2 × p × (1-p)) / MDE²
     - 若测试功效不足（<80%）则标记
   - **时长**：测试是否至少覆盖 1-2 个完整业务周期？
   - **随机化**：是否有样本比例失衡（SRM）的证据？
   - **新奇/首因效应**：是否有足够时间让初期的行为变化消退？

3. **计算统计显著性**：
   - 对照组与变体的**转化率**
   - **相对提升**：(variant - control) / control × 100
   - **p 值**：使用双尾 z 检验或卡方检验
   - **置信区间**：差值的 95% CI
   - **统计显著性**：p < 0.05 是否成立？
   - **实际显著性**：提升对业务是否有实际意义？

   如果用户提供原始数据，生成并运行 Python 脚本计算上述指标。

4. **检查护栏指标**：
   - 是否有护栏指标（营收、参与度、页面加载时间）恶化？
   - 核心指标获胜但护栏指标恶化，可能不是真正的胜利

5. **解读结果**：

   | 结果 | 建议 |
   |---|---|
   | 显著正向提升，无护栏问题 | **发布**——全量推到 100% |
   | 显著正向提升，护栏有隐患 | **先调查**——发布前弄清取舍 |
   | 不显著，但有正向趋势 | **延长测试**——需要更多数据或更大效应 |
   | 不显著，走势平稳 | **停止测试**——未检测到有意义差异 |
   | 显著负向提升 | **不发布**——回滚到对照组，分析原因 |

6. **输出分析摘要**：
   ```
   ## A/B 测试结果：［测试名称］

   **假设**: [我们预期的结果]
   **时长**: [X 天] | **样本**: [对照组 N / 变体 M]

   | 指标 | 对照组 | 变体 | 提升 | p 值 | 是否显著 |
   |---|---|---|---|---|---|
   | [核心指标] | X% | Y% | +Z% | 0.0X | 是/否 |
   | [护栏指标] | ... | ... | ... | ... | ... |

   **建议**: [发布 / 延长 / 停止 / 调查]
   **理由**: [为什么]
   **下一步**: [该做什么]
   ```

一步一步思考。结果保存为 Markdown。若提供原始数据，生成 Python 脚本进行计算。
