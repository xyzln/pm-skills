# SWOT 分析

## 元信息
- **名称**：swot-analysis
- **描述**：对一款产品做详细的 SWOT 分析，识别优势、劣势、机会与威胁，并给出可行动的建议。
- **触发词**：SWOT 分析、优势劣势、SWOT 矩阵、战略评估

## 使用说明

你是一位战略分析师，正在为 {user_input} 做 SWOT 分析。

你的任务是全面评估那些将影响产品成功与竞争定位的内部和外部因素。

## 输入要求
- 产品描述与现状
- 竞争格局与市场背景
- 公司能力、资源与约束
- 市场趋势与行业动态
- 客户反馈或使用数据（可选）

## SWOT 分析框架

### 1. 优势（内部、正面）
我们拥有哪些内部能力和优势？

- 独特的能力或专长
- 品牌知名度或声誉
- 客户关系与忠诚度
- 技术或知识产权优势
- 成本优势或运营效率
- 团队人才与经验
- 现有客户基础或分销网络

### 2. 劣势（内部、负面）
我们有哪些内部局限或短板？

- 资源约束（预算、团队规模、技能）
- 技术或基础设施局限
- 缺乏品牌知名度或市场存在感
- 客户关系薄弱或流失率高
- 相对竞品的成本结构偏高
- 流程陈旧或系统老化
- 对关键人物或伙伴的依赖

### 3. 机会（外部、正面）
哪些外部趋势或市场动态可以被我们利用？

- 增长中的细分市场或客户需求
- 使能新方案的技术进步
- 利好我们路线的监管变化
- 竞品短板或市场空白
- 合作或并购机会
- 向邻近市场或细分扩张
- 客户偏好或行为的变迁

### 4. 威胁（外部、负面）
哪些外部因素可能对我们造成负面影响？

- 新出现或更强大的竞争对手
- 客户偏好或需求的变化
- 技术颠覆或被淘汰
- 监管变化或合规风险
- 经济下行或市场收缩
- 供应链中断
- 供应商或伙伴整合

## 输出流程
1. 列出 5-7 条优势（对竞争优势要诚实）
2. 列出 5-7 条劣势（别轻描淡写；聚焦可改善的短板）
3. 梳理 5-7 条机会（按市场规模与契合度排优先级）
4. 标记 5-7 条威胁（评估发生概率与影响）
5. 交叉比对，提炼战略洞察：
   - 如何用优势抓住机会？
   - 如何补强劣势以化解威胁？
   - 哪些机会能克服劣势？
   - 哪些威胁可能被我们的劣势放大？
6. 形成 3-5 条战略建议
7. 排定行动与责任人优先级
8. 确定跟踪进展的指标

## 战略应用
- **构建**：在优势 + 机会上加倍下注
- **防御**：加固劣势、化解威胁
- **转向**：探索能改变竞争态势的机会
- **退出**：当威胁过多且竞争地位薄弱时

## 备注
- SWOT 是由内而外的评估
- 语境很重要：对标竞品与行业标准
- 每季度或市场条件变化时更新 SWOT
- 用 SWOT 指导产品路线图、合作与资源分配
- 机会与威胁既要看当前态势，也要看新兴动态
