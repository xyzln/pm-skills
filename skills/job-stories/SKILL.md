# 任务故事（Job Stories）

使用「当……时，我想……，以便……」（When [situation], I want to [motivation], so I can [outcome]）格式创建任务故事。生成的故事附带详细验收标准，聚焦用户情境与结果。

**使用时机：** 撰写任务故事、表达用户情境与动机、创建待办任务（JTBD）风格的需求池条目，或需要聚焦用户情境而非角色时。

**参数：**
- `$PRODUCT`：产品或系统名称
- `$FEATURE`：要拆分为任务故事的新功能
- `$DESIGN`：设计文件链接（Figma、Miro 等）
- `$CONTEXT`：用户情境或任务场景

## 分步流程

1. **识别触发需求的用户情境**
2. **定义用户行为背后的动机**
3. **澄清用户想达成的结果**
4. **应用待办任务（JTBD）框架：** 聚焦任务本身，而不是角色
5. **创建验收标准**，验证结果已达成
6. **使用可观察、可度量的语言**
7. **链接设计稿**或原型
8. **输出任务故事**，附带详细验收标准

## 故事模板

**标题：**【任务成果或结果】

**描述：** 当【情境】时，我想【动机】，以便【结果】。

**设计：**【设计文件链接】

**验收标准：**
1. 【情境被正确识别】
2. 【系统支持用户达成期望的动机】
3. 【进展或反馈可见】
4. 【结果被高效达成】
5. 【边界情况被妥善处理】
6. 【集成与通知正常工作】

## 任务故事示例

**标题：** 查看每周零食预算余额

**描述：** 当我在规划本周的零食零花钱时（情境），我想快速看到目前已花了多少（动机），以便确保周末前不会把钱花光（结果）。

**设计：**【Figma 链接】

**验收标准：**
1. 支出汇总页展示「每周支出总览」板块
2. 记一笔支出后实时更新
3. 进度指示（进度条显示本周预算已用 0-100%）
4. 剩余预算用醒目颜色高亮
5. 详细支出流水按品类拆分
6. 预算用到 80% 时发通知
7. 周四晚上用到 90% 时发「周末专项」提醒
8. 一键进入明细，导航便捷

## 产出交付物

- 该功能的完整任务故事集
- 每个故事都遵循「当……我想……以便……」格式
- 6-8 条聚焦结果的验收标准
- 故事突出用户情境与动机
- 与设计和原型有清晰链接
