# 同期群分析与留存探索器

## 目的

按同期群分析用户参与度和留存模式，识别用户行为、功能采用和长期参与度的趋势。把定量洞察与定性研究建议结合起来。

## 工作方式

### 第 1 步：读取并校验数据
- 接收带有用户同期群信息的 CSV、Excel 或 JSON 数据文件
- 校验数据结构：同期群标识、时间段、参与度指标
- 检查缺失值和数据质量问题
- 汇总关键统计量（同期群规模、日期范围、可用指标）

### 第 2 步：生成定量分析
- 计算同期群留存率和参与度趋势
- 识别留存曲线、流失模式和异常
- 计算各同期群的功能采用率
- 计算环比或期环比变化
- 如需，生成使用 pandas 和 numpy 的 Python 分析脚本

### 第 3 步：创建可视化
- 生成留存热力图（同期群 × 时间段）
- 创建展示同期群进展的折线图
- 制作功能采用对比图
- 可视化流失点和参与度趋势
- 输出为交互式图表或静态图片

### 第 4 步：识别洞察与模式
- 发现一个或多个显著模式：
  - 特定同期群的早期流失
  - 后期参与度变化
  - 功能采用聚集带
  - 季节性/时间性趋势
- 高亮令人意外的发现和偏离
- 比较同期群表现，建立基线

### 第 5 步：建议后续研究
- 推荐定性研究方法：
  - 对流失用户做定向访谈
  - 对高参与同期群做功能使用调研
  - 对关键交互模式做会话回放
  - 对高留存 vs. 低留存同期群做得失分析
- 设计后续定量研究
- 建议 A/B 测试或功能实验

## 使用示例

**示例 1：上传 CSV 数据**
```
上传 cohort_engagement.csv，列包括：cohort_month、weeks_active、
user_id、feature_x_usage、engagement_score

请求："分析留存模式，找出 2025 年 Q4 同期群相比 Q3 表现不佳的原因"
```

**示例 2：描述数据格式**
```
"我有 2025 年 1-12 月的月度用户同期群。每行包含：
同期群日期、用户 ID、购买频次和客服工单数。
分析哪些同期群的长期留存最好。"
```

**示例 3：功能采用分析**
```
上传 feature_usage.xlsx（包含同期群采用数据）。

请求："比较新功能在各同期群中的采用曲线。
哪些同期群采用最快？有什么模式？"
```

## 核心能力

- **数据读取**：导入 CSV、Excel、JSON、SQL 查询结果
- **留存分析**：计算并可视化留存率随时间的变化
- **同期群对比**：跨同期群分组比较指标
- **异常检测**：标记异常模式或流失
- **Python 脚本**：生成可复用的分析代码，支持持续分析
- **可视化**：创建热力图、图表和交互式仪表盘
- **研究设计**：建议有针对性的后续研究和访谈方法
- **统计摘要**：提供定量指标和相关性分析

## 获得最佳结果的建议

1. **带上时间维度**：提供跨多个时间段的数据
2. **清晰定义同期群**：明确同期群分组方式（注册月份、功能上线日期等）
3. **提供背景**：说明期间内的产品变更、上线或事件
4. **多个指标**：包含留存、参与度、功能使用、收入等
5. **数据充足**：至少 3-4 个同期群才能识别出有意义的模式
6. **明确要求的输出**：提出要可视化、Python 脚本还是研究建议

## 输出格式

你会收到：
- **数据摘要**：同期群概览和数据质量评估
- **定量发现**：关键指标、留存率和趋势分析
- **可视化**：展示留存曲线、采用模式的图表
- **模式识别**：从数据中得出的 2-3 个显著洞察
- **研究建议**：具体的定性和定量后续动作
- **分析脚本**（如需）：可复现分析的 Python 代码
- **下一步**：基于发现排好优先级的行动
