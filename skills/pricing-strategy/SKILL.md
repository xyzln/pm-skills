## 定价策略

设计一套立足于价值交付、竞争定位和支付意愿的定价策略。

### 背景

你正在为 **{user_input}** 制定定价策略。

如果用户提供了文件（竞品价格、调研数据、财务模型或用量数据），先读取。必要时用网络搜索调研竞品定价。

### 操作步骤

1. **理解交付的价值**：
   - 核心价值主张是什么？
   - 客户的替代方案是什么（成本多少）？
   - 产品能带来哪些可量化的结果？（节省的时间、增加的收入、降低的成本）
   - 基于这些价值，客户的支付意愿如何？

2. **评估定价模型**——推荐最匹配的一款：

   | 模型 | 最适用场景 | 示例 |
   |---|---|---|
   | **一口价** | 产品简单、成本可预测 | Basecamp（固定价 约 ¥699/月） |
   | **按席位** | 协作工具、团队产品 | 钉钉、飞书 |
   | **按用量** | 基础设施、API 产品 | 阿里云、腾讯云 |
   | **分层套餐** | 用户分层清晰的产品 | 多数 SaaS 产品（免费版 / 专业版 / 企业版） |
   | **Freemium（免费增值）** | 有病毒式 / 网络效应的产品 | 网易云音乐、B站 |
   | **Freemium + 用量** | 平台型产品 | Vercel、OpenAI API |
   | **价值定价** | 高价值的企业级工具 | Salesforce、Palantir |

3. **分析竞品定价**：
   - 梳理竞品价格档位及各档包含什么
   - 明确你的产品所处位置（高端、中端、低端）
   - 找到价格空档或机会
   - 留意行业定价惯例

4. **设计价格结构**：
   - **档位：** 定义 2-4 档，差异化要清晰
   - **功能门控：** 哪些功能放哪一档？（用价值指标划分，不要拍脑袋设限）
   - **计价指标：** 你按什么单位收费？（用户数、事件数、存储量、API 调用次数）
   - **锚定定价：** 让最热门的档位看起来是显而易见的选择
   - **年付折扣：** 通常比月付便宜 15-20%

5. **估算价格敏感度**：
   - 有调研数据时可用 Van Westendorp 价格敏感度测试（PSM）：
     - 太便宜 → 怀疑质量
     - 便宜 → 物有所值
     - 偏贵 → 开始犹豫
     - 太贵 → 不会买
   - 或者，基于竞品定价和交付的价值来估算

6. **规划定价实验**：
   - A/B 测试定价页（不同价格点、档位名称、功能组合）
   - 创始人亲自出马的销售沟通，测试支付意愿
   - 用不同价格锚点测试落地页
   - 按价格点做同期群（Cohort）转化率分析

7. **输出定价建议**：
   ```
   推荐模型：[模型类型]
   计价指标：[你按什么收费]

   | 档位 | 价格 | 目标客群 | 核心功能 | 定位 |
   |---|---|---|---|---|

   关键假设：
   - [假设] → [如何验证]

   风险：
   - [风险] → [缓解措施]
   ```

一步步思考。以 Markdown 保存。对上线前需要验证的假设要做标记。
