# SQL 查询生成器

## 用途

把自然语言需求转化为跨多个数据库平台的优化 SQL 查询。本技能帮助产品经理（PM）、分析师和工程师在不手动编写语法的情况下生成准确查询。

## 工作方式

### 第 1 步：理解你的数据库结构
- 如果你提供结构文件（SQL、文档或图表描述），我会读取并分析它
- 提取表名、字段定义、数据类型和关系
- 识别主键、外键和索引策略

### 第 2 步：处理你的请求
- 厘清你需要检索或分析的具体数据
- 确认 SQL 方言（BigQuery、PostgreSQL、MySQL、Snowflake 等）
- 询问其他要求（筛选、聚合、排序）

### 第 3 步：生成优化查询
- 编写善用你库表结构的高效 SQL
- 附上解释复杂逻辑的注释
- 补充大数据量下的性能考量
- 适用时提供替代写法

### 第 4 步：解释与测试
- 用平实的语言解释查询逻辑
- 建议如何测试或验证结果
- 给出性能优化建议
- 如果需要，生成测试脚本或示例数据

## 使用示例

**示例 1：基于结构文件查询**
```
上传你的 database_schema.sql 文件，然后说：
「生成一个查询：找出最近 30 天注册、
并且至少有 5 次活跃会话的用户」
```

**示例 2：基于图表描述查询**
```
「这是我的数据库：Users 表（id, email, created_at），Sessions 表
（id, user_id, timestamp, duration）。生成一个查询：
统计 2026 年 1 月每个用户的平均会话时长。」
```

**示例 3：复杂分析查询**
```
「写一个 BigQuery 查询：按地区和客户层级分析我们的收入，
包含同比增长率。」
```

## 核心能力

- **多方言支持**：支持 BigQuery、PostgreSQL、MySQL、Snowflake、SQL Server
- **文件读取**：可读取结构文件、SQL 转储和数据文档
- **查询优化**：建议索引、分区和性能改进
- **解释说明**：拆解查询，便于学习和沉淀文档
- **测试**：可生成测试查询和示例数据脚本
- **脚本执行**：为你的数据库创建可执行的 SQL 脚本

## 获得最佳效果的技巧

1. **提供背景**：分享你的数据库结构
2. **说具体**：清楚描述你需要的数据和筛选条件
3. **说明数据库**：指明你用的 SQL 方言
4. **带上约束**：说明数据量、时间范围和性能要求
5. **指定格式**：需要特定输出时，说明查询结果的格式

## 输出格式

你将收到：
- **SQL 查询**：带注释、可直接投产的 SQL 代码
- **解释**：查询做什么、怎么工作
- **性能说明**：优化建议与考量
- **测试脚本**（如需要）：示例数据与验证查询
