# 增长闭环

## 概述

识别并设计能创造可持续牵引力的增长闭环（增长飞轮）。本技能评估五种经过验证的增长闭环机制，以减少对付费获客的依赖，构建产品驱动增长（PLG）。

## 何时使用

- 为一款产品设计增长机制
- 构建可持续的病毒式或推荐牵引力
- 减少对付费获客的依赖
- 分析竞品的增长策略
- 为产品驱动增长（PLG）优化产品

## 5 种增长闭环类型

### 1. 病毒式闭环

用户在产品内创作的内容被分享到外部平台，把新用户带回产品。

- **机制：** 用户在产品内创作 → 分享到社交/外部平台 → 新用户发现并注册
- **示例：** 腾讯文档/飞书文档的链接分享、在企业微信或钉钉里转发的录屏链接
- **优势：** 若内容天生适合分享，用户获取可指数级放大
- **挑战：** 需要高度可分享的产出和强分享激励

### 2. 使用闭环

用户在产品内创作内容或价值，然后分享出去，邀请来新用户或带动回流活跃。

- **机制：** 用户创作 → 分享作品 → 他人消费 → 成为活跃用户
- **示例：** 微博长文、知乎回答、公开分享的飞书/语雀文档模板
- **优势：** 增长与产品使用和网络效应直接挂钩
- **挑战：** 要求内容创作的摩擦非常低

### 3. 协作闭环

用户邀请同事在产品内共同创作或协作，在组织内部扩张用户基数。

- **机制：** 用户创作 → 邀请同事协作 → 同事发现产品价值
- **示例：** 腾讯文档的协作邀请、飞书项目、钉钉群/企业微信中的协作
- **优势：** 组织渗透深、留存高
- **挑战：** 最适合协作型/团队型产品

### 4. 用户生成闭环

用户通过其他用户的创作发现新内容或功能，然后创作并分享自己的内容。

- **机制：** 用户发现内容 → 创作类似内容 → 分享作品 → 他人发现
- **示例：** 抖音、小红书、B站 的热点带动创作者参与
- **优势：** 形成内容飞轮和网络效应
- **挑战：** 需要临界规模的优质内容才能持续

### 5. 推荐闭环

用户用奖励、激励或社交认可换取对其他潜在用户的邀请。

- **机制：** 用户推荐 → 被推荐者加入 → 推荐者获得奖励 → 分享更多推荐
- **示例：** 滴滴打车"推荐有礼"、美团/饿了么的邀请红包、支付宝拉新奖励
- **优势：** 直接激励获客，容易衡量投入产出
- **挑战：** 激励要有价值，同时不侵蚀单位经济模型

## 运作方式

### 第 1 步：定义产品价值

澄清用户体验到的核心价值：

- 用户在产品中采取的主要行动
- 每次用户行动创造的价值
- 存在的网络效应（如有）
- 体验中的摩擦点

### 第 2 步：评估闭环契合度

评估哪些增长闭环与你的产品匹配：

- 产品类型（协作型、内容型、工具型等）
- 目标用户行为与分享习惯
- 已经存在的网络效应
- 现有用户基数与活跃度

### 第 3 步：设计闭环机制

设计具体的闭环实现：

- 触发分享或邀请的时机
- 参与激励（内在或外在）
- 分享机制的便捷程度
- 从邀请到激活的转化率
- 每个用户重复闭环的频率

### 第 4 步：计算闭环系数

估算增长速度：

- 每个用户每轮发出邀请/分享数
- 邀请到新用户的转化率
- 每轮净增用户数
- 每轮迭代所需时间

### 第 5 步：搭建闭环

先实现杠杆最高的闭环：

- 从你的产品最自然的闭环起步
- 优化话术与摩擦
- 衡量闭环指标与转化率
- 让结果随时间复利

## 输入格式

用 {user_input} 传入：

- 产品描述与主要用户行动
- 目标用户属性与行为
- 已有的分享/协作功能
- 当前增长渠道与指标
- 约束或机会

## 输出

一份增长闭环分析，包括：

- 针对你的产品对全部 5 种闭环类型的排序评估
- 推荐的主增长闭环及实施计划
- 后续逐层叠加的次级闭环
- 关键指标与衡量框架
- 30-60-90 天实施路线图
- 潜在闭环系数与增长预测

## 框架

基于 Ognjen Bošković 的增长闭环研究，聚焦通过内建于产品、原生于产品的分享与协作机制实现用户获取的复利。

## 提示

- 先精通一个闭环，再叠加复杂度
- 病毒式闭环复利最快，但搭建需要时间
- 协作闭环创造最强的留存与客户终身价值（LTV）
- 优化阶段每周衡量闭环健康度
- 一旦规模化运转，组合多个闭环可产生乘法效应
